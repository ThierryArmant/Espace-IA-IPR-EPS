Invitations, groupes et accès des collaborateurs.

Inviter : saisissez l’adresse académique, puis envoyez le lien proposé par courriel (valable 48 heures). Pour ajouter beaucoup de personnes d’un coup, utilisez « Ajouter des personnes » dans Autorisations.

Inviter un collaborateur

{% call help_menu('aide-inviter', 'Aide sur l’invitation', 'Inviter une personne') %}

Pour une seule personne : tapez son adresse académique, puis « Préparer l’invitation ».

Le Hub affiche un lien personnel, valable 48 heures, et ouvre un brouillon de courriel dans votre messagerie : relisez, puis envoyez.

La personne clique sur le lien, choisit son mot de passe, et son compte devient actif. Pensez à lui ouvrir des dossiers dans Autorisations.

{% endcall %}

Inviter en une fois

{% call help_menu('aide-inviter-tous', 'Aide sur l’invitation groupée', 'Inviter plusieurs personnes') %}

Prépare d’un coup un courriel pour chaque compte encore « en attente d’activation » (par exemple les personnes ajoutées par liste dans Autorisations).

« Qui inviter » : tout le monde, ou seulement les membres d’un groupe (pratique pour commencer par les IPR).

La page suivante affiche un bouton « Ouvrir le courriel » par personne : cliquez, vérifiez, envoyez. Les liens sont valables 48 heures ; refaire l’opération crée de nouveaux liens.

{% endcall %}

Prépare un courriel par compte en attente d’activation (ajouté par exemple depuis Autorisations).

Créer un groupe

{% call help_menu('aide-groupes', 'Aide sur les groupes', 'À quoi servent les groupes ?') %}

Un groupe rassemble des personnes pour leur donner quelque chose en une seule fois, au lieu de le faire personne par personne.

Deux groupes utiles ici :

• Gestion des autorisations (nom exact) : ses membres peuvent modifier le tableau Autorisations.

• IPR (ou le nom de votre choix) : à choisir ci-dessous comme « groupe des applications » ; ses membres partagent Événements, Réunions, Créneaux, Questionnaires, Marque-pages et Publications.

Comment faire : tapez le nom, cliquez sur « Créer », puis, dans « Comptes » plus bas, cochez le groupe sous le nom de chaque personne et cliquez sur « Enregistrer les groupes ».

Un groupe peut aussi recevoir des droits sur un dossier, dans « Droits d’accès ».

{% endcall %}

Par exemple « IPR » ou « Gestion des autorisations ».

Groupe des applications IPR

{% call help_menu('aide-groupe-applications', 'Aide sur le groupe des applications', 'Qui utilise Événements, Réunions… ?') %}

Les applications de la barre de droite (Événements, Réunions, Créneaux, Questionnaires, Marque-pages, Publications) sont partagées entre les membres d’un groupe.

Comment faire : 1. créez le groupe (par exemple « IPR ») dans « Créer un groupe » ; 2. choisissez-le ici et cliquez sur « Enregistrer le groupe » ; 3. dans « Comptes », cochez ce groupe pour chaque personne concernée.

Tant qu’aucun groupe n’est choisi, ces applications restent vides.

{% endcall %}
