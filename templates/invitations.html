Dans la boîte {{ sender }} : nouveau message, collez les adresses dans Cci (copie cachée, pour que personne ne voie les autres adresses), puis l’objet et le message.

Rien n’est envoyé par l’espace : cette page prépare le courriel, vous l’envoyez depuis votre messagerie. Pour annuler, fermez simplement la page.

  1. Avant le premier envoi, faites un essai : dans une fenêtre de navigation privée (Ctrl+Maj+N), ouvrez la page de connexion et cliquez sur « Se connecter avec mon compte académique ».
  2. Gardez cette page ouverte. Dans un autre onglet, ouvrez la messagerie de {{ sender }} et cliquez sur « Nouveau message ».
  3. Faites apparaître le champ Cci (copie cachée) : en général, un clic sur « Cci » à droite du champ « À ».
  4. Ici, cliquez sur 1, puis collez (Ctrl+V) dans Cci.
  5. Cliquez sur 2, puis collez dans Objet.
  6. Cliquez sur 3, puis collez dans le corps du message.
  7. Relisez, puis Envoyer. Si la messagerie exige un destinataire, mettez {{ sender }} dans « À ».
