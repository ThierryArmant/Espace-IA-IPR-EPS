PRISE EN MAIN

Aide

L’essentiel pour travailler dans l’espace IA-IPR EPS.

1. Trouver un document

Cliquez sur Documents dans la barre de droite. À gauche, l’explorateur affiche les dossiers qui vous sont ouverts. Arrêtez la souris sur un dossier principal pour voir ses sous-dossiers, ou cliquez sur la flèche ›.

Le cadenas vert indique un dossier auquel vous avez accès ; le cadenas rouge, un dossier visible dont le contenu est fermé.

Dans un dossier, cliquez sur le nom d’un document pour le consulter, ou sur Télécharger. La zone « Rechercher dans ce dossier » filtre la liste.

2. Déposer et créer

Si vous pouvez contribuer à un dossier, vous y trouvez :

  • Importer des documents : déposer des fichiers depuis votre ordinateur ;
  • Tableur (Collabora) et Texte (Collabora) : comme Excel et Word, pour un planning, une note, un courrier ;
  • Tableur (Grist) : pour une liste que chacun complète (inscriptions, remontées) ;
  • Document (Docs) : pour écrire à plusieurs en même temps (compte rendu, prise de notes) ;
  • Ranger un lien Grist ou Docs : ajouter au dossier le lien d’un tableur ou d’un document créé dans ces outils.

Grist et Docs s’ouvrent avec votre compte académique ; partagez-y aussi vos documents avec les collègues concernés.

3. Prévenir les collègues

Après une mise à jour importante, cliquez sur Notifier à côté du document : les collègues autorisés le verront dans Notifications.

4. Travailler en groupe

Événements, Réunions, Créneaux, Questionnaires, Marque-pages et Publications sont partagés entre les membres du groupe. Chaque page a sa bulle ?.

5. Un doute ?

Cliquez sur les boutons ? présents sur chaque page : ils expliquent la zone où ils se trouvent. Pour un accès manquant, contactez l’animateur de l’espace.
