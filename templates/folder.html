＋ Tableur (Grist) ＋ Document (Docs) {% call help_menu('aide-outils', 'Aide sur les outils', 'Quel outil choisir ?') %}

Tableur (Collabora) — comme Excel. Pour un planning, une répartition, un budget. Le fichier est créé tout de suite dans ce dossier ; « Modifier à plusieurs » l’ouvre dans un autre onglet (il faut un accès au dossier dans Nuage pour modifier).

Texte (Collabora) — comme Word. Pour un courrier, une note, un document mis en page. Même fonctionnement.

Tableur (Grist) — pour une liste que chacun complète : inscriptions, remontées des établissements, suivi. Grist peut ne montrer à chacun que ses lignes.

Document (Docs) — pour écrire à plusieurs en même temps, simplement : compte rendu de réunion, prise de notes.

Grist et Docs s’ouvrent dans un autre onglet avec votre compte académique. Une fois le tableur ou le document créé, copiez son adresse, puis utilisez « Ranger un lien Grist ou Docs » pour l’ajouter à ce dossier. Seules les personnes autorisées sur ce dossier verront le lien.

Pensez à partager aussi le tableur ou le document avec vos collègues dans Grist ou Docs.
